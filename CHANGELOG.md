## [0.1.0] - 2026-08-03

### Added

- Deterministic layered layout for compound workflow graphs.
- Native `.dtui` syntax and DAWL JSON graph input.
- Plain text, ANSI, SVG, and interactive terminal rendering.
- Orthogonal routing with explicit ports and waypoints.
- Finite DAWL NDJSON event replay with stable layout.
- Cross-platform CI, source-policy checks, and end-to-end fixtures.
